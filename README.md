## 上云互联优化入口 IXP 是什么，和 IEPL 差在哪

一句话：IXP 入口产品等于把专线入口搬进了互联网交换中心，只对“圈内成员”广播。IXP（Internet Exchange Point，互联网交换中心）是电信运营商和云厂商互换流量的节点，同一交换中心内的网络互访走内部直连路径，接近内网体验。近几年阿里云、腾讯云、华为云等国内云厂陆续接入各地 IXP（包括深圳前海 IX 这类新型交换中心），商家才得以把专线入口架进这个圈子。

链路长这样：


本地设备 → 国内大厂前置 VPS → IXP 内网入口 → 专线 → 海外出口


和传统 IEPL/IPLC 相比，差别集中在两点。第一，入口隐蔽。没有公网 IP，扫描器和举报都够不着入口，这是它抗通报能力强的根源，做 NAT 分流也不用像公网入口那样频繁换 IP。第二，风险转移。IEPL 的 DDoS 防护、两端配置由商家包办；IXP 把前置机被攻击、被封的风险留给了用户。NodeSeek 上的讨论帖把这事说得很直白：这类产品最高的门槛反而在前置，实惠又能接入 IX 的前置基本只有阿里云、腾讯云的轻量档。

Mkcloud 的 IXP 产品定位也很明确：给已经在用阿里云、腾讯云、华为云、UCloud 等云厂的用户，用云厂 BGP 网络当前置入口，再接自家专线出口。它家 2023 年成立，全线产品要求实名认证并限正规用途，支持支付宝付款，所有套餐都配独立 IP。

## 前置机怎么选，整套要花多少钱

前置优先选离你物理位置近的大厂节点。大厂 VPS 基本是 BGP 混合线路，跨省流量大多走自家内网，损耗很低，所以人在北京也可以给深港线配北京节点的前置。攻略里的参考数据：广东节点前置访问深港 IX 入口延迟在 10ms 以内，访问上海入口约 30 多 ms。

成本上，整套系统等于“前置月费 + IXP 线月费”。有攻略作者给出的组合示例是阿里云新人套餐 68 元/年，搭配 20 元/月的独享 IX 服务。前置尽量薅新用户活动，但廉价套餐可能藏每日限速策略；同一攻略的体验是腾讯云的限速没有阿里云明显，下单前把套餐条款翻一遍。

再算一笔 IXP 和 IEPL 的账：同为端内延迟 1~2ms、2TB 月流量，深港 IXP 是 158 元/月，广港 IEPL 是 568 元/月，一年差 4920 元。前提是你能接受前置防护自理；想省心开箱即用，IEPL 贵出来的钱买的就是这部分服务。

和优化线路 VPS 对比也类似。DMIT 日本三网 CN2 GIA 的入门款月付 21.9 美元、只有 500GB 流量；深港 IXP 2TB 档 158 元/月，流量是它的四倍。IX 方案前期折腾得多，跑顺之后成本和稳定性都占优。

Mkcloud 还有个和多数 IX 商家不同的点：单端双独立 IP。市面上大部分 IX 产品出口是共享 NAT IP（俗称万人骑），想要干净出口得自备落地机；Mkcloud 入口和出口各给一个独立 IP，第三方整理的评分资料显示其 IP 的 scamalytics 评分可到 0，对 Amazon、TikTok Shop 这类风控严格的平台友好。如果你只需要一个干净出口 IP，落地机的钱可以省下来。

## 搭建流程：两段转发就能跑通

整条链路只需要配两处：前置机的端口转发，和本地客户端的节点地址。因为 Mkcloud 给了独立出口 IP，业务可以直接跑在 IX 机器上，不需要第三台落地机。

1. 买前置，确认云厂和地域在支持列表。验证方法很朴素：SSH 登录前置后 ping 专线入口 IP，能通就能用。
2. 在前置上装端口转发工具（Gost、Realm、iptables 都可以），监听一个本地端口，转发到 Mkcloud 分配的入口 IP 和入站端口。
3. 到云厂控制台的安全组放行前置的监听端口，这一步最容易漏。
4. 本地客户端把服务器地址改填前置 IP 和监听端口，链路即通。
5. 出口按需处理：直接用独立出口 IP 跑业务，或有分流需求时再挂落地机。

## 常见问题

**上云互联优化入口 IXP 和 IEPL/IPLC 到底怎么选？**

核心看入口是否暴露公网。IXP 入口只对交换中心成员网络广播，抗通报、被扫描概率低，但要自备前置、防护自理；IEPL/IPLC 开箱即用，商家包防护和两端配置，同规格价格更高。图省心选 IEPL，已有大厂云、能自己运维就选 IXP。

**没有云服务器，能直接买 Mkcloud 的 IXP 产品吗？**

不能直接用。入口只对 IXP 成员网络开放，必须先买一台支持列表内的云厂 VPS 做前置，再确认地域可用、完成实名。

**流量超了会怎样？**

深港 IXP 产品超量停机。按业务月流量选档，峰值业务建议留两到三成余量。

**要实名吗？适合什么人用？**

要。全线中国身份实名、限正规用途，禁止机场和回国类用途；部分产品还有省级白名单。适合跨境电商、跨境办公、游戏加速这类长期、稳定的正规需求。
